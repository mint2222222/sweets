# sweets

A plate of desserts slowly spinning in your terminal, in 3D ASCII. A toy, like `sl`.

```
./sweets.py                  # a pile of macarons
./sweets.py cheesecake       # also: tiramisu, pancakes, donuts, mochi, birthday, cherrypie
./sweets.py --birthday NAME  # cake with flickering candles
./sweets.py --peaks          # cherry pie and black coffee, in the red room
./sweets.py --color          # gruvbox; also: term, amber, green
./sweets.py --help
```

Keys: `space` next, `e` eat, `r` serve again, `c` clock, `s` screensaver, `+`/`-` speed, `q` quit.

Pure Python 3, no dependencies. Run `python3 test_sweets.py` for the self-check.
